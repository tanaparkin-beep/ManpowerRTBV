# ผังกำลังพล RTB (Manpower RTB)

หน้าเว็บผังอัตรากำลัง Rapid Transit System Business ตามโครง TOR 362 อัตรา

- `index.html` — ผังกำลังพลฉบับเต็ม (พนักงาน, โยกย้าย, TOR vs HR, คุณสมบัติ GCC / MA MRT / Construction MRT)
- `tor.html` — โครงอัตรากำลังตาม TOR อย่างเดียว (ไม่มีข้อมูลพนักงาน)

ทั้งสองหน้ามีรหัสผ่านเข้าใช้งาน 2 ระดับ (เห็น / ไม่เห็นเงินเดือน) ข้อมูลเงินเดือนถูกเข้ารหัส AES-GCM ไว้ในไฟล์ และถอดรหัสในเบราว์เซอร์เมื่อใส่รหัสระดับเห็นเงินเดือนเท่านั้น
